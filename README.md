# The LEAP Type Test - GitHub Pages Upload

This folder is ready for manual GitHub Pages upload.

## Files

- `index.html` - the complete mini-game. The character artwork is embedded, so no asset folder is required.
- `README.md` - this guide.

## Manual GitHub Pages Steps

1. Upload `index.html` and `README.md` to the repository root, replacing the old files.
2. Go to `Settings` > `Pages`.
3. Under `Build and deployment`, choose `Deploy from a branch`.
4. Choose branch `main` and folder `/root`, then save.
5. Wait 1-2 minutes.
6. If the old version still appears on phone, open the URL with `?v=share-card-fix` once to bypass cache.

## Tracking Notes

Registration links go to the event introduction page first and include UTM parameters plus quiz result type, for example `utm_content=result_cta` and `leap_type=ALFC`.
