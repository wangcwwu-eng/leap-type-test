# The LEAP Type Test - GitHub Pages Upload

This folder is ready for manual GitHub Pages upload.

## Files

- `index.html` - the complete mini-game. The character artwork is embedded, so no asset folder is required.
- `README.md` - this guide.

## Manual GitHub Pages Steps

1. Create a new public GitHub repository, for example `leap-type-test`.
2. Upload `index.html` and `README.md` to the repository root.
3. Go to `Settings` > `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Choose branch `main` and folder `/root`, then save.
6. Wait 1-2 minutes.
7. The site URL will be:

```text
https://YOUR-GITHUB-USERNAME.github.io/leap-type-test/
```

## Tracking Notes

Registration links include UTM parameters and the quiz result type, for example `utm_content=result_cta` and `leap_type=ALFC`.
